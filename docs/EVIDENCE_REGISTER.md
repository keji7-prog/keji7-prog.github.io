## Housing reproducibility

To check the **complete** public summary with an authorized local copy of the captured CSV:

```bash
python projects/housing_analysis.py path/to/beike_listings.csv --verify data/housing_aggregate_v8.json
```

The public script regenerates the entire `groups` and `price_bands` structures, overall medians, record count, source URL and collection time. Python's normal ties-to-even rounding applies to integer unit-price medians; the two-bedroom median is **54,784.5** before rounding and **54,784** after rounding.

## Source hierarchy

1. Actual source records / official API responses
2. Saved execution logs and analysis scripts
3. Reproducible derived metrics
4. User-facing charts and screenshots

A visual design or user-interface preview never supersedes the source records. Do not describe older dated values as current; do not infer changes over time from a single snapshot. Preserve original files and notes when correcting derived outputs.
