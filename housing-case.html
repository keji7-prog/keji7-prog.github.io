PROJECT PIPELINE

数据处理流程

01 / COLLECT

浏览器数据提取

使用 DrissionPage 访问列表页，解析网页结构、字段信息与房源详情链接。

02 / CLEAN

结构化整理与校验

提取面积与户型字段，将价格转为数值；检查空值、重复链接和字段完整性。

03 / ANALYZE

汇总统计与可视化

通过 Pandas 计算中位数、户型分布与价格区间，输出可复现的汇总数据。
